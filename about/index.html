Perfect TV

IPTV-плеер для смарт-ТВ: свой плейлист M3U, программа передач XMLTV, архив, гид в духе привычного телевизора — с пульта. Бесплатно, с открытым кодом (GNU GPL 3.0).

IPTV player for smart TVs: your own M3U playlist, XMLTV programme guide, catch-up, a familiar TV-style guide — all from the remote. Free and open source (GNU GPL 3.0).

LG webOS

webOS 3.0 и новее (ТВ с 2016 года). Ставится в режиме разработчика.

  1. В LG Content Store — приложение «Developer Mode», вход в аккаунт LG Developer, «Dev Mode Status» — вкл.
  2. На компьютере с Windows — установщик Perfect TV из релиза: он найдёт ТВ и поставит приложение.

Режим разработчика живёт около 50 часов — установщик его продлевает.

webOS 3.0 and newer (2016+ TVs). Installed in Developer Mode.

  1. Install “Developer Mode” from LG Content Store, sign in with an LG Developer account, turn “Dev Mode Status” on.
  2. On a Windows PC run the Perfect TV installer from the release: it finds the TV and installs the app.

Developer Mode lasts about 50 hours — the installer extends it.

Samsung Tizen

Tizen 3.0 и новее (ТВ с 2017 года). Ставится в режиме разработчика через Apps2Samsung — он сам сделает сертификат Samsung под ваш ТВ.

  1. На ТВ: Apps → ввести 12345 → Developer mode — вкл., IP — адрес компьютера, перезагрузить ТВ.
  2. Apps2Samsung на компьютере или телефоне → Perfect TV (или файл .wgt из релиза) → «Install».

Tizen 3.0 and newer (2017+ TVs). Installed in Developer Mode via Apps2Samsung — it creates the Samsung certificate for your TV.

  1. On the TV: Apps → type 12345 → Developer mode on, IP = your computer’s address, restart the TV.
  2. Apps2Samsung on a computer or phone → Perfect TV (or the .wgt from the release) → Install.

Браузер, VIDAA, Titan OS, MSX

Browser, VIDAA, Titan OS, MSX

Приложение открывается по адресу — без установки:

perfect-tv.github.io

MSX (Media Station X): «Settings → Start Parameter → Setup», ввести perfect-tv.github.io и включить замок (HTTPS) — Perfect TV будет открываться при запуске MSX.

Только адреса https://: страница открыта по HTTPS, и браузер не загрузит плейлист, программу и каналы по http://. Для них и для серверов без CORS — прокси: perfect-tv.github.io/?proxy=http://адрес:порт.

The app runs from an address — nothing to install:

perfect-tv.github.io

MSX (Media Station X): “Settings → Start Parameter → Setup”, enter perfect-tv.github.io and turn on the lock (HTTPS) — Perfect TV will open when MSX starts.

https:// addresses only: the page runs over HTTPS, so the browser will not load playlists, guides or channels over http://. For those and for servers without CORS use a proxy: perfect-tv.github.io/?proxy=http://host:port.
